# NetHunter Security Lab

Coyot3Labs kapsamında Kali NetHunter öğrenme ve laboratuvar çalışmalarını belgelemek için oluşturulmuş depo.

## Amaç

- Mobil güvenlik ve Linux temellerini öğrenmek.
- Kurulum ve sorun giderme çalışmalarını düzenli biçimde belgelemek.
- İzinli laboratuvar testleri için tekrar kullanılabilir notlar hazırlamak.

## Kapsam

Bu depo eğitim amaçlıdır. Uygulamalar yalnızca sahip olunan veya açıkça izin verilen sistemlerde gerçekleştirilir.

## Durum

Depo oluşturuldu. Teknik çalışma notları ve ekran görüntüleri henüz eklenmedi.
